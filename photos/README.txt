AJD Mobile Mechanic — photos for the review/work showcase
==========================================================

Drop job photos in THIS folder (jpg or png), then add one line each to the
SHOWCASE list near the bottom of index.html (search for "const SHOWCASE").

Example — a photo entry looks like this:

  { type:'photo', src:'photos/brake-job.jpg', caption:'Brakes done curbside — Liberty, NY' },

A review entry looks like this:

  { type:'review', quote:'Their exact words here.', meta:'NAME — TOWN · VIA GOOGLE' },

IMPORTANT: end EVERY line with a comma, even the last one. That keeps the list
from breaking no matter what you add or remove.

The showcase automatically crossfades between every entry once there are 2 or
more. Keep photos landscape or portrait, under ~500 KB each so the page stays
fast. For a before/after pair, add two photos back to back with captions like
"Before — no-start in the driveway" and "After — back on the road."
